# Cartera

Gestor personal del balance y la evolución de productos económicos: cuentas, depósitos y fondos de inversión.


## Dependencias

You need libsecret-1-dev and libjsoncpp-dev on your machine to build the project, and libsecret-1-0 and libjsoncpp1 to run the application.

* build-packages:
  - libsecret-1-dev
  - libjsoncpp-dev
* stage-packages:
  - libsecret-1-0
  - libjsoncpp-dev
